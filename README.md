# DelGames

A small arcade of the puzzle games we keep coming back to — built with Next.js, ready to deploy on Vercel.

## Games

- **Word Streak** (live) — our "Chain" game. Player 1 builds a 5-word chain where each word connects to the next. Player 2 sees the first word and the first letters of the rest, then reveals letters or guesses their way down the chain.
- **Codenames Duet** (coming soon)
- **Dial It In**, a Wavelength-style game (coming soon)

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploying

Push to GitHub and import the repo in [Vercel](https://vercel.com/new) — no config needed, it's a standard Next.js app.
